# Security

To report a vulnerability, use **Report a vulnerability** on the repository's [Security page](https://github.com/ericflo/durable-db/security/advisories/new). That report is private. Please do not open a public issue for it.

Fixes are made on `main` and shipped in the next release; only the latest release is maintained. What the protocol guarantees, what has been checked and what has not is in [`docs/verification.md`](docs/verification.md).
